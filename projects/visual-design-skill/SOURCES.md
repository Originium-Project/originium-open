## Tensions resolved in the instructions

- Grid organizes content; it does not require rigid equal cards. Repetition gives predictable roles; it need not create ornament.
- Dashboard glanceability identifies a lead and routes to exact detail; it does not require every fact above the fold or forbid scrolling.
- Data-ink restraint removes non-informative marks while retaining scales, useful chart guides, units, caveats, and numeric alternatives.
- Progressive disclosure hides uncommon depth, never the inputs, warnings, or comparison basis needed for a safe decision.
- Web contrast/reflow criteria are scoped to web content; PDF tag order, native app behavior, and terminal cell/semantic behavior need their own checks.
